- ### 快速开始（详情请观看⬆️视频）
1. **▶️ Fork本仓库** - 点击页面上绿色“Fork”按纽

2. **🚀 ComfyUI起飞** - 点击页面上“ComfyUI起飞”按纽

3. **⌛ 等待启动** - 进入云开发环境界面后，最上面会显示显卡负载，并开始自动下载模型，然后启动ComfyUI，如显卡负载很大，可跳到第7步结束掉重开。

4. **🟢 ComfyUI启动** - ComfyUi启动完成后，会在右下角弹出打开Web页面提示，点击打开，也可找到端口菜单，打开后再点“转发地址”。

5. **💡 运行工作流** - 右侧找到菜单工作流，内有包括图片、视频、音频、Ai动画等几十个工作流，打开后点击运行，就可以直接跑起来。

6. **⬆️ 推送上传** - 如对工作流、插件等进行了修改，请在命令行上面运行：git_push.sh，将修改内容同步到自己的仓库。

7. **❌ 关机结束** - 终端输入命令：kill 1；或者菜单：云原生开发 中 点关闭，关闭前请注意保存数据。

## 📦 模型管理

#### 🟢 仓库中已有工作流都已经完成了模型的配置，直接点运行，会自动从云端拉取仓库到本地，然后加载运行，无需手动干预。

### 🧩 添加CNB平台已有模型：

- #### 方法一：手动编辑：/workspace/assets/source_2.json 文件，参考里面的格式：将模型文件链接和模型文件名加入，保存后重启ComfyUI。

- #### 方法二：模型编辑器：命令行中：运行：python3/workspace/assets/tools/web_editor.py，打开Web版的模型编辑器，载入：source_2.json文件，进行添加，保存后重启ComfyUI。

### 🤖 添加自有模型：

- #### 先将模型上传到CNB平台上：Fork仓库：https://cnb.cool/zhan_zhi/Comfy-Models，启动后，在命令行进行模型下载或者本地上传，然后使用仓库说明中的命令同步推送到CNB平台，然后用上面的2个方法中的一种修改：source_2.json文件完成加入。

#### 🟢 请在本地电脑上面备份：/workspace/assets/source_2.json文件，后期重新Fork后，重新上传：source_2.json，自己的模型就恢复了。
